# Каталог и продуктовые подписи · 8 октября 2026

По запросу пользователя исправлена компоновка каталога и убраны упоминания demo/synthetic из продуктового интерфейса. Это изменение представления: происхождение данных, not_assessed, границы доступа и assessment-категории остаются в серверном контракте и документации.

## Что изменено

- «Рынок · демо» переименован в «Рынок», вакансии/просмотр/пагинация получили обычные названия. URL использует `market=profiles|vacancies`; старый `demo_market` принимается и заменяется при открытии. Фильтры и страницы сохраняются.
- Собственная `.market-grid` использует ограниченный шириной контейнера минимум колонки. Карточки получили явные отступы 24/20px, переносы текста и единый flex-layout; кнопки выровнены по низу ряда. Описание ограничено тремя строками, навыки двумя; весь текст доступен в CV. Фильтры и модальное окно также получили отступы и адаптивные размеры.
- Зарплата без значений показывается одной строкой «Зарплата не указана». Неполный диапазон показывает «от»/«до», а не повтор «не указано — не указано».
- Удалены служебные бейджи, баннеры и пояснения в регистрации, профиле, ФСП, вакансиях, карточках, доказательствах, продвижении и воронке. Источник непроверенного результата обозначен нейтрально; mock-запись ФСП не становится подтверждённой.
- `presentation.ts` преобразует отображаемый текст из исходных fixtures: названия компаний, CV, доказательства и причины приглашения. Вымышленные числовые иллюстрации в рассказе не отображаются; содержимое импортированного корпуса не перезаписывается. Идентификаторы, контакты и API metadata не преобразуются. Префиллы имени/описания/компании очищаются при загрузке формы; сохраняются только при явном обычном действии пользователя.
- Переключатель real/synthetic в воронке скрыт. Как и прежнее начальное поведение, UI выбирает real-срез, если в нём есть активность, иначе synthetic; счётчики не складываются. Обе группы остаются отдельно в API.

## Проверки

Production TypeScript/Vite build успешен. Браузерные проверки каталога проверяют границы карточек, минимум 20px padding, отсутствие горизонтального overflow и выравнивание кнопок при 1440, 1180, 1024, 768 и 390px. Проверяется отсутствие служебных слов во всех основных кандидатских/HR-разделах, CV и сравнении; просмотр условий, фильтры, reload, исходный unassessed статус и запрет CV для кандидата сохранены.

Общий браузерный прогон: 24 passed, 2 failed, 3 skipped. Два падения были связаны с устаревшими ожиданиями подписей; проверки обновлены под новые тексты. Повторный прогон файлов core-flow и employer-pipeline завершился успешно: 8 passed. Таким образом, все 26 обычных браузерных сценариев прошли в совокупности этих прогонов; три сценария с live AI в этой итерации не запускались. Промежуточные попытки повторного запуска прерывались из-за потери соединения с тестовыми серверами; последний запуск этих файлов завершился без ошибок.

Собранная статика скопирована в существующий web-контейнер без пересборки Docker-образов. Отдельная проверка уже обновлённого сайта на порту 58080 не выполнена: пользователь попросил остановить работу и Docker из-за нехватки места на C:. Backend/БД/миграции этой итерацией не изменяются; предыдущая полная PostgreSQL/SQLite-проверка записана в [отчёте импорта](validation/synthetic-market-integration-results.md).
