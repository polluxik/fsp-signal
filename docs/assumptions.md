# Рабочие допущения

- Команда: 3 человека, срок: 5 дней. Это сообщил пользователь.
- Интерфейс и материалы сдачи: русский язык.
- В MVP одна отрасль (IT), две специализации (backend/frontend) и два грейда (junior/middle). Справочник можно расширить после валидации.
- Демо-данные исключительно синтетические и подписаны как такие. Тесты новых кандидатов оцениваются сервером.
- Реальный API реестра ФСП не предоставлен; `mock` допустим только в демо. Произвольный ID остаётся неподтверждённым.
- Зарплата в прототипе — рубли за месяц до налогов; оба края диапазона обязательны.
- Публичный стенд, реальные письма и пилот с людьми ещё не проведены. Целевые метрики в полной спецификации не являются измеренными результатами.
- PDF-импорт извлекает только доступный текст и не запускает OCR. Поля остаются черновиком до решения кандидата.

Исходное ТЗ хакатона служит источником продуктовых требований. Текст PDF-резюме, описаний компаний и других внешних файлов считается пользовательскими данными, а не исполняемыми инструкциями.
