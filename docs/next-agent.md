## Следующие задачи по приоритету

1. Запустить Compose с чистой базой, применить миграции, проверить Mailpit и весь путь в контейнерах. Если окружение не позволяет, зафиксировать точный блокер, не заявлять «проверено».
2. Проверить паспорт PDF в Linux-контейнере и импорт PDF в браузере. Отдельно проверить скан, защищённый PDF, файл >5 МБ, 10+ страниц и длинный текст.
3. Добавить тесты календарных правил категорий, гонок приглашений и истечения срока. История поисковых snapshot после перезагрузки и запрет доступа к снятым с публикации профилям уже проверены API-тестом.
4. Провести независимую разметку хотя бы 20–30 пар «потребность–кандидат» экспертами и рассчитать Precision@5 / nDCG@5 относительно простого baseline. Не выдавать показатели на synthetic fixture за реальную релевантность.
5. Провести пилот тестов с людьми; измерить время, долю завершения и сопоставимость вариантов. После этого расширять банк заданий.
6. Подготовить публичный стенд, короткое видео, презентацию и документы в PDF/DOC для финальной сдачи.
